# pleno-pii-scanner-azure-devops

Azure DevOps `SourceConnector` for [pleno-pii-scanner](../pii-scanner/).
Implements ADR-0007 §13 (per-host wheel) and Task #20.

## Coverage

| capability | status |
| --- | --- |
| Azure DevOps Services (`dev.azure.com/{org}`) | yes |
| Azure DevOps Server (on-prem TFS successor) | yes (`flavor="server"` + `base_url`) |
| PAT auth (basic, empty user) | yes |
| OAuth 2 access token (Bearer) | yes |
| Federated identity / OIDC token exchange (Microsoft Entra) | yes |
| Project enumeration (`continuationToken` header pagination) | yes |
| Repo enumeration per project (`isDisabled` filter) | yes |
| Repository content scan (shallow `git clone --depth=1`) | yes (seam: `clone_fn`) |
| Rate limiting (`Retry-After` on 429) | yes |
| Self-signed CA for Server (`ca_bundle_path`) | yes |

## Why a hand-rolled httpx wrapper

The official `azure-devops` Python SDK is sync-only and pulls msrest +
msrest-azure + a 6 MB autogenerated surface we'd touch <1% of. We hit
two endpoints (`_apis/projects` and `_apis/git/repositories`) and a
single AAD token endpoint for federated identity — httpx + tenacity is
~150 lines and shares the test-transport seam with the rest of the
scanner.

## Auth modes

```toml
# Personal Access Token
[credential]
mode = "pat"
pat = "<70-char ado pat>"

# OAuth 2 / Entra ID access token
[credential]
mode = "oauth"
access_token = "<bearer token>"

# Federated workload identity (GitHub Actions OIDC, AKS, etc.)
[credential]
mode = "federated"
oidc_token_path = "/var/run/secrets/azure/tokens/oidc"
tenant_id = "<entra tenant uuid>"
client_id = "<app registration uuid>"
```

The federated path posts the OIDC JWT as the `assertion` parameter to
`https://login.microsoftonline.com/{tenant}/oauth2/v2.0/token` against
the Azure DevOps resource scope
`499b84ac-1321-427f-aa17-267ca6975798/.default`. The exchanged bearer
is cached until 5 minutes before its `expires_in`.

## On-prem (Azure DevOps Server)

```toml
[source]
flavor = "server"
base_url = "https://tfs.example.internal/DefaultCollection"
ca_bundle_path = "/etc/ssl/certs/internal-ca.pem"
project = "Banking"
```
